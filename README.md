Project Overview:-

BookEase Hotel Booking System is a full-stack web application designed to make hotel room booking simple and convenient. It allows users to register, log in, browse hotels, view available rooms, book rooms, complete the payment process, and view their bookings.The system also provides an Admin Dashboard where administrators can manage hotels, rooms, users, and bookings.

How to Run BookEase Hotel Booking System:-
Step 1: Database Setup (XAMPP)
Open XAMPP Control Panel -> Start Apache + MySQL -> Open phpMyAdmin -> Create a database named:hotel_booking -> Create/import the required tables for:Users, Hotels, Rooms, Bookings

Step 2: Backend Setup
Open the terminal and go to the backend folder:
cd backend -> Install the required packages:npm install -> Start the backend server:node server.js -> The backend will run on:http://localhost:5000

Step 3: Frontend Setup
Open another terminal and go to the project folder:cd hotel_booking -> Install the frontend dependencies:npm install
Start the React application:npm start -> The frontend will run on:http://localhost:3000
